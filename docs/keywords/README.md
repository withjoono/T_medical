## 만든 방식

- **대상**: 2027학년도 수시에서 의예과 면접을 실시하는 **37개 의대**
  (전체 39개교 중 가톨릭관동대 · 충북대는 면접 미실시라 제외)
- **축**: `대학 표기` × `의대 표기` × `면접 용어`
- **띄어쓰기 없음** — 네이버 검색광고는 공백을 구분하지 않으므로 붙임 형태로만 만들었습니다.
- 약칭은 **실제로 검색되는 표기만** 넣었습니다. 만들어낸 줄임말은 넣지 않았습니다.

**T2가 이 목록의 핵심입니다.** 대학마다 실제 유형에 맞는 용어만 붙였습니다.

- MMI 실시교(11) → `mmi` · `mmi면접` · `다중미니면접`
- 인·적성 실시교(22) → `인적성면접` · `생기부면접` · `서류확인면접`
- 제시문 실시교(4) → `제시문면접` · `제시문`

연세대는 제시문 면접이므로 `연세대의대mmi` 를 만들지 않았습니다. 헛돈이 나가는 조합입니다.
