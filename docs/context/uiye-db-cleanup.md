# 의예과 전형 DB 정정 목록 (2026-10-19)

2027학년도 수시 모집요강 원문 대조 중 발견한 `lib/ipkyul/uiye.ts` 의 오류·중복이다.
**수능최저·선발모형 보강은 이미 반영**했고, 아래는 사람이 판단해야 하는 항목이다(코드 반영 여부는 고치기 전에 파일에서 확인).

| 대학 | 전형명 | DB 모집 | 근거 |
|---|---|---|---|
| 충북대 | 특수교육대상자전형 | 2명 | 해당 전형 모집단위에 의과대학 없음. 2는 지역경제배려대상자전형 의예과 인원과 동일 |
| 단국대 | 교육기회배려자 | 2명 | 의학·약학계열 없음. 의예과 정원외 2명은 농어촌학생으로 보임 |

## 4. 중복 행 (같은 값을 채워 둠 — 전형 수가 부풀려짐)

- 울산대 4쌍: 지역교과/지역교과 특별전형, 지역인재/지역인재 특별전형, 잠재역량/잠재역량 특별전형, 지역인재(기초/차상위) 3행
- 충북대: 학생부종합Ⅰ 3행, Ⅱ 2행, 지역의사광역권 3행, 충주·제천 진료권 각 2행
- 전북대 2쌍(지역인재1유형-호남권 / 2유형-전북권, "전형" 유무 차이)
- 원광대 지역인재=지역인재종합전형 · 연세대 학생부종합전형[활동우수형]=활동우수형 · 중앙대 융합형인재=학생부종합(융합형인재) · 건양대 지역[기초]=지역기초 · 계명대 학생부종합(의사 진로)=학생부종합(지역의사진료전형)
- 대구가톨릭대 지역의사선발(진료권) 권역별 6행+통합 2행 · 한림대 지역의사 권역별 7행+통합 2행 · 가톨릭관동대 지역의사선발 권역별 5행+통합 1행

## 5. 다계열 합산 행 — 처리 완료

`quotaByType` 합계 제외 + 표에 "타 계열 합산" 표시: 대구가톨릭대 `지역교과 (의예과, 약학부)` 358(의예 19 + 약학부 15), 인제대 `의예·약학` 33(의예 25 + 약학 8), 인제대 `기초생활수급권자` 0.

## 6. 끝내 못 채운 9행

- 울산대 6행 — 2027 의예과를 뽑지 않는 전형(quota 0)
- 계명대 3행 — 입학처 원문 확인 불가. 언론상 '수학 포함 상위 3개 합 5 이내'이나 원문 미확인이라 비워 둠
