# 데이터 원칙·원천·필터

## 1. 게시 원칙 — 데이터 완결성보다 우선

- **실측만 싣는다.** 입결컷 원본의 `자료출처` 는 `입결+어디가`(실측)와 `추정(계열)` 로 나뉜다.
  추정치는 `lib/ipkyul/*.ts` 에 **아예 넣지 않는다.** cut 이 없는 전형은 `—`/'공시 입결 없음'으로 비운다.
  의대는 1.2와 1.4가 당락을 가르므로 계열 평균을 입결로 내보내면 오지원을 만든다.
  - 빌드 산출물에 `추정(계열)` 문자열이 0건인지 확인한다.
  - `예상컷(yesangcut_*)`·`합불(hapbul_*)` 을 쓰게 되면 '입결'이 아니라 **'예상 합격선(추정)'** 으로 이름과 섹션을 분리한다.
- **요강이 밝히지 않은 값은 `요강 미기재`** 로 남긴다. 추정해서 채우지 않는다.
- 확정 날짜가 없으면 `announce: null` + `announceAssumed` + `announceNote`(근거) — 페이지가 "미공지 / (예정)"으로 표기한다.
- 대학별 수치(논술 실시 대학, 최저 기준)는 출처마다 집계가 달라 단정하지 않는다. "최종 모집요강 기준" 문구를 유지한다.
- 수치를 고치면 각 페이지 하단 `SourceNote`·`sources` 의 **기준 시점·출처도 함께** 고친다.
- 선생님 경력은 `lib/teachers.ts` 에 등록된 credential 만 노출한다. 코드가 경력을 지어내지 않는다.

## 3. 계열 필터 규칙 (`unit.csv`)

이름 정규식만 쓰면 `전 모집단위(… 의예과 …)` 같은 열거형 행 2,081개가 섞여 의예 인원이 16,584명으로 부푼다.
**`소계열` + 이름 + 열거형 배제** 를 함께 건다.

| 계열 | 소계열 | 이름 포함 | 제외 |
|---|---|---|---|
| uiye | `의학` | 의예\|의학과\|의학부 | 한의\|수의 |
| chiuiye | `치의학` | 치의예\|치의학 | |
| hanuiye | `한의학` | 한의예\|한의학 | |
| suuiye | `동물ㆍ수의학` | 수의예\|수의학 | |
| yakhak | `약학` | 약학 | 한약 |

- 열거형 배제 = 모집단위명 30자 초과 또는 `전 모집단위|통합모집|자율전공|자유전공` 포함
- 수동 보정: 부산대 한의학전문대학원 학·석사통합과정(소계열 `의학` 오분류) → 한의예로 편입
- 수능최저는 **전형 단위 텍스트**라 다른 학과 안내가 섞여 있다. `app/ipkyul/_ipkyul.tsx` `pickMinimum()` 이
  **그 행의 모집단위명에서 키워드를 뽑아** 해당 문장만 남긴다. 고정 키워드 목록을 쓰면 `혁신신약학과` 가 `약학` 에 걸린다.
- 다계열 합산 행(대구가톨릭대 `지역교과 (의예과, 약학부)`, 인제대 `의예·약학`)은 `quotaByType` 합계에서 빼고 "타 계열 합산"으로 표시한다.

## 4. 면접 분류 — 두 축, 그리고 대학이 진입 단위

- **질문 출처(source)** 생기부/제시문/현장 문항 과 **평가 배점(scoring)** 인성·적성 비율/역량 비율 은 서로 다른 축이다. 한 대학이 둘 다일 수 있다. 하나로 묶지 말 것(`lib/field-interview.ts`).
- 방문자가 아는 것은 **지원 대학 이름**이다. 허브의 진입 단위는 유형이 아니라 대학(대학 그리드 + 한눈에 표, 면접일 빠른 순, 미공지는 맨 아래).
- 한눈에 표 칼럼 순서: 대학 · 권역 · 방식 · 면접 전형 · 1차 발표 · 면접일. 1차 발표는 가장 이른 면접 전형 기준, 수능 전 면접에는 `수능 전` 표시.
- 분류 근거는 각 대학 `format[]` 의 요강 문장. **요강이 "MMI 아님"이라고 못박은 대학은 면접실이 둘이어도 mmi 로 넣지 않는다**(동아대·한양대·연세대).
- **MMI는 의예과에만 있다**(2027 전수 확인). 치의예·한의예·약학·수의예에는 없다. 을지대는 2028부터 MMI 예고.
- 강원대는 2027부터 MMI 폐지(확인 면접 1실, `style: "none"`). 고려대 학업우수전형은 2027 면접 미실시. 면접 미실시 의대: 가톨릭관동대·충북대.
- 생기부·서류확인형은 인·적성에 통합(질문 출처가 생기부라 준비법이 같다).
