# 모의면접 세트 — T메디 제작 (2026-11-13)

사용자 지시: "서울대 의대 MMI 문제와 채점기준을 만들어라. 모의면접으로 채점과 등수까지. 일반·지역균형 둘 다, 한 명씩 본다, T메디 AI 모의면접 화면에 넣을 데이터로."

기출 분석 근거는 Claude 프로젝트 문서 `claude/snu-mmi-gichul-analysis-2026-11-13.md`.

## 지킬 것

1. **기출 세트와 섞지 않는다.** `lib/interview-sets.ts` 는 "질문을 지어내지 않는다"가 원칙이고(data-rules.md 4-2), 이 파일은 전부 창작이다. source.kind `자체 제작`, 화면에 "서울대 기출이 아닙니다"를 항상 띄운다.
2. **채점기준은 T메디 기준이다.** 서울대는 질문·채점기준을 공개하지 않는다. "서울대 채점기준"으로 읽히는 문구 금지. 점수·등급은 합격 예측이 아니다.
3. **`draft: true` — 선생님 검수 전.** 이세인·류지연 선생님 검수 뒤에 뗀다.
4. **등수는 실제 누적 기록으로만.** 표본 30명 미만이면 등수를 띄우지 않는다. 가짜 분포·임의 숫자 금지.
5. **면접관 메모(memo)는 서버 전용.** 공개 파일에는 `snuMockPublicSets()` 만. 다만 채점기준 글(`grading.rubricText`)은 규격상 공개 파일에 들어가므로 학생이 미리 볼 수 있다 — 감추려면 서버에서만 주도록 엔진을 고쳐야 한다.
6. 말투·유창함은 점수에 넣지 않는다("AI는 자연스러움을 점수화하지 않는다" — business-decisions.md).

## 채점

- 역량 6개: 독해·요지 15 / 분석·추론 20 / 판단·근거 20 / 관점 전환·공감 15 / 압박 속 일관성 15 / 확장·전달 15.
- 방마다 역량별 1~5점. 방 점수(100) = Σ 비중 × (점수 ÷ 5) − 감점(건당 5, 방마다 최대 15). 총점 = 네 방 평균.
- 등급(기준 도달): S 88↑ · A 76↑ · B 64↑ · C 52↑ · D.
- 등수: 같은 세트 · 실전 모드 · 방 4개 완료 기록 중, 사람당 **첫 응시** 점수만 모아 비교. 동점은 압박 속 일관성 → 분석·추론 → 판단·근거 순.

## 아직 화면에 안 붙었다 — 남은 일 (이 리포 밖)

지금 `/interview/ai` 의 MMI 실전 탭은 서버(susi-back `/interview-sim`)가 형식과 문항을 주고, 피드백은 기준 6가지의 충족 여부만 낸다("점수나 합격 가능성은 내지 않습니다"). 코치(iframe)는 `grading` 을 읽지 않는다. 그래서:

1. **susi-back interview-sim** — 이 세트 2개를 형식·문항으로 등록(`snuMockSets()` 출력), 방 종료 때 역량별 1~5점과 감점을 내도록 채점 프롬프트 확장, 총점 저장, 등수 조회 API(`rankOf` 와 같은 규칙).
2. **T메디 `_mmi-sim.tsx`** — 결과 화면에 방 점수·총점·등급·등수 표시, "점수는 내지 않습니다" 문구 교체. 서버 응답 타입(`lib/interview-sim-api.ts`)에 점수 필드 추가.
3. **확정(2026-11-13 사용자)** — 서울대 모의면접은 점수·등급·등수를 화면에 낸다. 기존 "점수 없음" 방침은 서울대 모의면접에 한해 바뀐다. 문항 8개와 채점표는 이세인·류지연 선생님 검수용 문서(Claude Docs)로 넘겼다.
4. 서류 기반 면접 방(20분)은 넣지 않았다. 생기부가 필요하고 T메디는 학생부를 받지 않는다(scope-boundaries.md) — 선생님 수업 몫.

## 수능 이후 의대 — 대학별 모의면접 1회 (2026-11-13 추가)

사용자 지시: "수능 이후 의대의 모의면접 문제와 채점기준을 1회씩 마련하라." 범위는 **33곳 전부 대학별로**, 순서는 **면접일 빠른 순**(사용자 선택).

- 파일: `lib/mock-sets/uidae-after-suneung.ts` — `UNIV_MOCKS`(만든 대학) · `PENDING_BY_DATE`(남은 대학, 면접일 순).
- 1차분 8곳(11/21~22 면접): 계명대 · 인제대 · 대구가톨릭대 · 연세대 · 이화여대 · 인하대 · 경북대 · 고신대.
- 2차분 12곳(11/25~29 면접): 경상국립대 · 전북대 · 강원대 · 동아대 · 울산대 · 건양대 · 가톨릭대 · 단국대 · 건국대 글로컬 · 영남대 · 연세대 미래 · 조선대. **남은 13곳**(12/1 이후 면접): 충남대 · 원광대 · 전남대 · 제주대 · 중앙대 · 한양대 · 동국대 WISE · 부산대 · 성균관대 · 경희대 · 한림대 · 아주대 · 가천대.
- 채점 틀 두 가지: 제시문·상황형(서울대와 같은 여섯 역량) / 서류·인성형(사실·구체성 20, 이해·설명 25, 성찰·배움 20, 진로·의료 연결 15, 꼬리질문 대응 20). 한 세트에 두 틀이 섞이면 문항의 `rubric` 으로 가른다.
- 서류확인·학생부 기반 면접은 질문이 학생마다 달라 공통 문항을 만들 수 없다. `DOC_POOL` 의 "자기 생기부에서 하나를 골라 답하는" 질문 틀로 연습한다 — 실제 질문과 같을 수 없다는 점을 화면에 밝힌다.
- 방 구성: 요강이 방별 시간을 밝힌 대학(계명 3실 × 10분, 인하 2실 × 7~8분)만 engine `mmi` 로 나눴다. 나머지는 방 하나(engine `question`). 준비 시간은 전부 T메디 설정.
- 대학의 평가요소·배점은 `format.scoring` 글로만 옮기고 점수 계산에는 쓰지 않는다(비중을 밝히지 않은 대학이 많다).
- **가천대도 만든다**(2026-11-13 사용자 확정). 수업 쪽의 "가천대는 AI 모의면접 없음"(business-decisions.md)과 어긋나므로, 화면에 붙일 때 그 문구를 함께 고친다.
- **서울대 외 대학도 점수·등급·등수를 화면에 낸다**(2026-11-13 사용자 확정). 규칙은 서울대와 같다(`BANDS`·`RANKING`).
